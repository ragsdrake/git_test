### obs-valorant-autoswitch

Lua-Skript fuer OBS Studio, das anhand des laufenden Windows-Prozesses
`VALORANT-Win64-Shipping.exe` automatisch zwischen einer "Game"-Szene und
einer "Idle"-Szene wechselt, sobald Valorant gestartet bzw. beendet wird.
Details zu Installation und Funktionsweise stehen in
[`obs-valorant-autoswitch/README.md`](obs-valorant-autoswitch/README.md).
